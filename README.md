# HanNamLang (HNL) — 요이~ㅋㅋ

> **엄.** 사람 말투가 어떻게 프로그래밍 언어냐고? **줴줴이야**.

HNL은 `엄.`, `티~원`, `예에에?`, `아뇨아뇨아뇨`, `요이~ㅋㅋ`, `줴줴이야` 같은 밈 표현으로 작성하는 **난해한 프로그래밍 언어(esolang)** 입니다. 파이썬 키워드를 단순히 치환한 언어가 아니라 **숫자 리터럴도 숫자로 적을 수 없고, 변수도 이름 대신 칸 번호로 다루는 실제 인터프리터**입니다.

[엄랭(umjunsik-lang)](https://github.com/rycont/umjunsik-lang)에서 영감을 받았으며 문법·구현은 독자적으로 작성했습니다. Python 3.10+만 있으면 실행됩니다. 외부 패키지는 필요 없습니다.

## 1. 설치 및 실행

```bash
git clone https://github.com/dh1180/HNL.git
cd HNL
python hnl.py examples/hello.hnl
python hnl.py examples/countdown.hnl
python -m unittest discover -s tests -v
```

`.hnl`은 HNL 소스 코드 확장자입니다.

## 2. 규칙

모든 프로그램은 `엄.`으로 시작해 `줴줴이야`로 끝납니다. 실행 가능한 명령은 **한 줄에 하나**입니다. 빈 줄과 `#`으로 시작하는 주석 줄은 무시합니다. 점프할 때 쓰는 명령 번호는 **시작/종료 구문과 빈 줄을 제외한 실행 명령의 1부터 시작하는 번호**입니다.

### 숫자 · 계산식

| 표현 | 의미 |
| --- | --- |
| `ㅋ` / `ㅋㅋㅋ` | +1 / +3 |
| `ㅠ` / `ㅠㅠ` | -1 / -2 |
| `ㅋㅠ` | 0 |
| `어` / `어어` | 첫 번째 / 두 번째 변수(없으면 0) |
| `ㅋㅋ~ㅋㅋㅋ` | 2 × 3 = 6 |
| `ㅋㅋ ㅠ 어어` | 2 - 1 + 두 번째 변수 |

`ㅋ`과 `ㅠ`가 섞인 한 묶음은 각 개수를 빼서 해석합니다. **띄어쓰기**는 덧셈, `~`는 곱셈을 나타냅니다. 괄호·일반 숫자·따옴표·문자열 리터럴은 없습니다.

### 명령어

| HNL | 뜻 |
| --- | --- |
| `엄.` | 프로그램 시작 |
| `엄~ <식>` | 1번 변수에 계산 결과 대입 (예: `엄~ ㅋㅋㅋ`) |
| `엄~~ <식>` | 2번 변수에 대입 (`~` 개수가 변수 번호) |
| `엄~ 예에에!` | 정수 하나 입력받아 1번 변수에 대입 |
| `요이~ㅋㅋ <식>` | 정수 출력 (개행 없음) |
| `요이~ㅋㅋㅋ <식>` | 해당 Unicode 코드 포인트의 문자 출력 |
| `요이~ㅋㅋㅋㅋ` | 줄바꿈 출력 |
| `티~원 <식>` | 계산 결과 번째 명령으로 무조건 이동 |
| `예에에? <식> : <식>` | 왼쪽 값이 **0**이면 오른쪽 명령 번호로 이동 |
| `아뇨아뇨아뇨 <식> : <식>` | 왼쪽 값이 **0이 아니면** 오른쪽 명령 번호로 이동 |
| `줴줴이야` | 프로그램 종료 |

모든 변수의 초기값은 0입니다. 명령 번호가 범위를 벗어나거나 잘못된 문자 코드가 입력되면 실행 오류가 발생합니다. 무한루프 방지를 위해 기본적으로 최대 1,000,000개 명령까지 실행합니다. `--max-steps`로 바꿀 수 있습니다.

## 3. Hello, World!

`examples/hello.hnl`은 문자열을 직접 쓰지 않고 각 글자의 Unicode 코드 포인트를 `ㅋ`과 `~`로 계산해 출력합니다.

```bash
python hnl.py examples/hello.hnl
# Hello, World!
```

## 4. 반복문 흉내내기

`examples/countdown.hnl`:

```text
엄.
엄~ ㅋㅋㅋㅋㅋ
요이~ㅋㅋ 어
엄~ 어 ㅠ
아뇨아뇨아뇨 어 : ㅋㅋ
요이~ㅋㅋㅋㅋ
줴줴이야
```

출력은 `54321` 다음 줄바꿈입니다. 명령 4에서 첫 번째 변수(`어`)가 0이 아니면 명령 2로 이동합니다.

## 5. 입력, 조건, 오류

`examples/input.hnl`은 정수 입력 및 `예에에?` 조건 분기를 보여줍니다. `HNL 오류: 4행: ...` 형태로 오류 줄을 표시하며 실패 시 종료 코드 1을 반환합니다. 조건 분기의 목표 명령 번호도 일반 HNL 식으로 작성해야 합니다.
